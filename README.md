# Cacatua — Windows x64

Текущий выпуск — **0.4.4 alpha**, commit `0d40292e0b7fba5d8e63f4ca0e1ae230d7a6fd5a`. [Сервер](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.4.4/Cacatua-server-0.4.4-windows-x64.exe) · [Клиент](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.4.4/Cacatua-client-0.4.4-windows-x64.exe) · [Описание выпуска](https://github.com/AbraSare/Cacatua-releases/releases/tag/v0.4.4).

**0.4.4 исправляет регрессию звука 0.4.2/0.4.3:** разрешения и списки микрофонов/выходов Electron, ошибочную остановку живого захвата при обновлении списка и временном mute, необработанный EPIPE помощника горячих клавиш. Добавлена диагностика этапов и очищенных исходных причин отказа. Возврат устройства не включает передачу автоматически. Ключи, аккаунты, комнаты, настройки и сохранённые отпечатки остаются прежними; старые установщики не заменяются.

Для скачивания не нужны аккаунт GitHub и токен. Репозиторий разработки остаётся приватным. Установщики пока без Authenticode; приложение проверяет Ed25519-подпись метаданных канала и SHA-256 пакета.

## Обновление 0.4.2/0.4.3 → 0.4.4

1. Сохраните исходную диагностику и версии. Сначала на **сервере** нажмите «Проверить обновления», дождитесь загрузки 0.4.4, завершите разговор и выберите «Установить…». Полный выход сервера — через меню трея; крестик только скрывает окно. Дождитесь отдельного окна установки и результата.
2. Запустите сервер, проверьте 0.4.4/commit выше, прежние аккаунты, HTTPS/TURN и отпечаток. Сервер принимает клиентов 0.4.2/0.4.3/0.4.4, однако старым оболочкам нужно собственное обновление для исправления разрешений микрофона.
3. Обновите **один проблемный клиент** тем же способом, затем проверьте звук. Если закреплены несколько серверов, сначала обновите все: несовместимый или недоступный сервер блокирует доставку. Не удаляйте отпечатки ради обхода проверки.
4. Проверьте сохранённые комнату, микрофон/вывод, громкости, порог/PTT и отпечаток. После успешной приёмки обновите остальных участников.

При ошибке сохраните диагностику отдельного окна и оболочки, время/часовой пояс и этап/код. Не очищайте профиль, кэш или отпечатки. Код 10 означает работающий экземпляр: завершите свои экземпляры штатно. Если старый updater не запускается, установите полный EXE той же роли поверх прежней версии под той же учётной записью Windows. Это ручное обновление, а не проверка штатного updater. Новый серверный ключ не нужен.

## Приёмка звука на ваших компьютерах

Повторите в отдельном клиенте и комнате серверной оболочки, с собеседником:
- Вход с микрофоном: список устройств заполнен, уровень движется, голос слышен, текст проходит.
- Вход без микрофона → включение → выключение → повторное включение; голос есть только при включённой передаче.
- Во время разговора выберите другой настоящий микрофон и другие наушники; после полного перезапуска выбор сохраняется.
- Отключите выбранное устройство и подключите снова. Микрофон не должен сам начать передачу. При необходимости выберите доступный вход и включите его явно; для выхода проверьте слышимость после явного выбора.
- Повторите с глобальными клавишами и без них. Ошибка помощника не должна закрывать приложение или ломать обычные кнопки. Для локального PTT при отказе helper явно выключите глобальный режим. Hunt проверяется отдельно.

При сбое сразу сохраните отчёт комнаты обоих участников и диагностику оболочки, укажите номер шага, время, роль/версию/commit и состояние глобальных клавиш. События `AUDIO_DEVICE` содержат этап, результат и очищенные `errorName/errorMessage`; `captureSuspended` обозначает временную приостановку живой дорожки.

## Подключение друга

Установите клиент, укажите публичный HTTPS-адрес сервера (домен или белый IP) и сверьте отпечаток с владельцем по независимому каналу. Зарегистрируйтесь по приглашению **аккаунта**, затем откройте отдельную ссылку **комнаты**. Сервер сохраняет прежнюю настройку HTTPS/TURN; обычно нужны TCP HTTPS-порт, UDP/TCP 3478 и UDP 49160–49200, настроенные владельцем. Приглашения и ссылка комнаты — разные секреты.

## Сохранённые возможности

- Индивидуальные громкость/«Заглушить для себя» сохраняются по аккаунту. Проверьте выход/возврат друга и перезапуск клиента: настройка применяется с первого звука, mute сохраняет выбранную громкость.
- В панели звука можно менять микрофон/вывод во время разговора. Подключите USB-гарнитуру, переключите голос, уведомления и локальную проверку. При потере микрофона передача закрывается; возвращение устройства не включает его само. Проверьте общий gain/deafen и сохранение DSP/PTT.
- Глобальные PTT/mute/deafen включаются в отдельном локальном окне; первоначально режим выключен. Для PTT также выберите «Нажми и говори» в комнате. Проверьте удержание и отпускание в свёрнутом Cacatua, затем в Hunt: Showdown. Ручной mute должен иметь приоритет, удержание mute/deafen не должно многократно переключать состояние. Запишите оконный режим и права запуска игры. Игра/античит и реальные устройства остаются ручной проверкой.
- «Настройки сервера → Управление пользователями…» открывает отдельное окно. Для действий нужна административная сессия; закрытие окна не останавливает сервер/разговор. Проверьте сворачивание, повторное открытие, выход и отзыв сессии. Используйте тестовые аккаунты.
- Приглашение комнаты можно свернуть/раскрыть без смены секрета. Копирование — отдельная кнопка. После смены комнаты или выхода прежние ссылки и административные данные скрываются.
- Звуковые уведомления 0.3.2 сохранены: семь переключателей, громкость 0–100%, явная проверка. PTT, шумовой порог и чужой mute не должны вызывать сигналов.

В 0.4.4 проверены настоящие Windows audio endpoints в обеих оболочках, перезапуск с сохранённым выбором и отказ собственного helper без потери захвата. Отдельно проверяется Electron/HTTPS/TURN с синтетическим PCM. Это не заменяет физическое USB/Bluetooth отключение и возврат, слышимость, акустическое эхо, Hunt и установку на ваших компьютерах.

При сбое сохраните время/часовой пояс, версии и commit обеих ролей, действие и код ошибки. Скачайте клиентский ZIP у каждого участника и серверный ZIP у владельца; при ошибке запуска — диагностику стартового окна, при установке — экспорт отдельного окна обновления. **Не публикуйте** пароли, ссылки с `#k=`, профили, резервные ZIP, базы, сертификатный private key или ключ издателя.

Постоянный подписанный канал: [client.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/client.json) · [server.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/server.json). Подпись, срок, совместимость, размер и hash проверяются приложением; просроченный feed продлевает издатель.

# Cacatua — установщики Windows x64

Публичные выпуски клиента и сервера. Для скачивания и работы канала обновлений аккаунт GitHub и токен не нужны. Репозиторий разработки остаётся приватным. Приложение — экспериментальная альфа; установщики пока без Authenticode-подписи.

## Переход с рабочей 0.3.0

1. Завершите разговор и полностью закройте приложения. Владелец сервера выбирает в трее **«Закрыть приложение и остановить сервер»**; крестик панели оставляет сервер работающим.
2. Один раз установите **0.3.1 поверх 0.3.0**, под прежним пользователем Windows. Не удаляйте приложения или профили. Владельцу нужен [установщик сервера 0.3.1](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.3.1/Cacatua-server-0.3.1-windows-x64.exe), каждому участнику — [клиент 0.3.1](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.3.1/Cacatua-client-0.3.1-windows-x64.exe). Commit: `0be69719d8cfe4859e77094c59af00d1b46743ee`.
3. Откройте приложения, проверьте прежний вход, комнаты, отпечаток сервера, голос и сообщения. В 0.3.0 ещё нет настроенного канала, поэтому этот первый переход автоматически невозможен.

## Проверка обновления до 0.3.2

1. В «Обновлении приложения» включите автоматическую проверку/загрузку. Для первого испытания временно отключите **«Устанавливать при полном выходе»**.
2. Во время разговора выполните «Проверить обновления» или дождитесь фоновой проверки. Дождитесь готовности 0.3.2: речь и текст должны продолжаться. Скачивать EXE 0.3.2 вручную для этой проверки не нужно.
3. Проверьте отсрочку на 24 часа и сохранение готового пакета после полного выхода и запуска. Снимите отсрочку, включите установку при полном выходе.
4. Сначала полностью закройте клиент, дождитесь установки и откройте его через обычный ярлык. Затем владелец предупреждает участников и полностью выходит из сервера через меню трея. После установки снова запустите сервер. Само закрытие панели в трей обновление не устанавливает.
5. Обе роли должны показывать **0.3.2**, commit `2fe55e3af9c1f8a57aed7f371ea53694de79e178`. Проверьте прежние данные, отпечаток, HTTPS/TURN, короткий разговор и сообщения. Недоступный закреплённый сервер может отложить установку клиента: готовый пакет сохраняется.

[Выпуск 0.3.2](https://github.com/AbraSare/Cacatua-releases/releases/tag/v0.3.2) содержит те же установщики для ручного восстановления. Подписанные Ed25519 метаданные доступны по постоянным адресам [client.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/client.json) и [server.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/server.json). Приложение проверяет подпись, срок, версию, совместимость, размер и SHA-256 пакета; просроченный feed издатель должен продлить, отключать проверки не требуется.

## Звуковые уведомления

После обновления **сервера до 0.3.2** в комнате доступны семь типов сигналов, общая громкость 0–100% и «Проверить». Настройки меняются во время разговора и сохраняются. Уведомления не меняют усиление речи/микрофона и не добавляются напрямую в отправляемый звук. При выключенном воспроизведении обычные сигналы подавляются; явная проверка допускает локальное прослушивание, но 0% остаётся тишиной.

Проверьте собственный вход/выход, вход/выход друга, свой mute/unmute и устойчивую потерю ранее установленной связи. PTT, шумовой порог, чужой mute, первый список участников и краткий восстановившийся обрыв не должны создавать лишние сигналы. Слышимость с настоящими наушниками/колонками и весь путь установки на разных компьютерах требуют ручной приёмки.

При сбое сохраните точное время, версии/commit обеих ролей, шаг проверки и код ошибки. Передайте владельцу диагностические ZIP клиента и сервера. **Не публикуйте здесь** пароли, ссылки с ключом комнаты, профили, резервные ZIP, базы, сертификаты или приватные ключи.

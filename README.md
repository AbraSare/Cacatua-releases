# Cacatua — Windows x64

Текущий выпуск — **0.4.3 alpha**, commit `c74649609cf56f94b5a5209a02c8923c1708bc67`. [Сервер](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.4.3/Cacatua-server-0.4.3-windows-x64.exe) · [Клиент](https://github.com/AbraSare/Cacatua-releases/releases/download/v0.4.3/Cacatua-client-0.4.3-windows-x64.exe) · [Описание выпуска](https://github.com/AbraSare/Cacatua-releases/releases/tag/v0.4.3).

**0.4.3 — без новых функций**, для проверки штатного автообновления из успешно установленной 0.4.2. Сервер 0.4.3 принимает клиентов 0.4.2 и 0.4.3; ключи и форматы данных прежние. Опубликованные файлы старых выпусков не заменяются.

Для скачивания не нужны аккаунт GitHub и токен. Репозиторий разработки остаётся приватным. Установщики пока без Authenticode; приложение проверяет Ed25519-подпись метаданных канала и SHA-256 пакета.

## Автообновление 0.4.2 → 0.4.3: сервер, затем один клиент

1. Сохраните исходную диагностику, версии/commit и настройки. На **сервере 0.4.2** откройте локальные настройки обновлений, нажмите «Проверить обновления» и дождитесь готовности 0.4.3.
2. Предупредите участников о перерыве. Нажмите «Установить…» и подтвердите полный выход. Крестик панели только скрывает её. Должно появиться **отдельное окно обновления**: ожидание выхода, проверка, резервная копия, установка, сверка результата.
3. После успеха нажмите «Запустить Cacatua». Проверьте сервер **0.4.3**, commit выше, прежние аккаунты, HTTPS/TURN и отпечаток. Подключите пока прежний клиент 0.4.2, проверьте текст и голос.
4. На остальных клиентах включите «Отложить установку на 24 часа», чтобы сохранить одного участника на 0.4.2 до конца испытания. На **одном проблемном ПК** запустите проверку обновлений клиента 0.4.2, дождитесь загрузки, затем установите с полным выходом через отдельное окно. Если закреплены несколько серверов, сначала обновите все: несовместимый или недоступный сервер блокирует установку. Не удаляйте отпечатки ради обхода проверки.
5. Запустите клиент **0.4.3**, сверьте commit, микрофон/вывод, усиление/порог/PTT, громкость/mute собеседника, уведомления, комнату и отпечаток. С оставшимся клиентом 0.4.2 проверьте текст и голос в обе стороны — сначала с принудительным TURN, затем в обычном режиме.
6. Зафиксируйте отдельно для каждой роли: обнаружено → загружено → отдельное окно → итоговая версия/commit → данные сохранены → разговор работает. После успеха обновляйте остальные клиенты.

Для этого испытания не запускайте полный EXE вручную поверх: это не проверяет штатное автообновление. При ошибке сначала экспортируйте диагностику отдельного окна, затем штатную диагностику сервера и клиентов. Запишите время/часовой пояс и этап/код. Не очищайте профиль, кэш или отпечатки. Код 10 означает работающий экземпляр: проверьте другие свои сеансы и завершите его штатно. «Повторить в Cacatua» заново проверяет канал и совместимость.

Для новых установок доступны полные EXE выше. Более старую сломанную версию можно обновить полным установщиком под той же учётной записью Windows после штатного выхода, сохранив профиль; такой путь фиксируйте как ручную установку. Создавать новый серверный ключ для обновления не нужно.

## Подключение друга

Установите клиент, укажите публичный HTTPS-адрес сервера (домен или белый IP) и сверьте отпечаток с владельцем по независимому каналу. Зарегистрируйтесь по приглашению **аккаунта**, затем откройте отдельную ссылку **комнаты**. Сервер сохраняет прежнюю настройку HTTPS/TURN; обычно нужны TCP HTTPS-порт, UDP/TCP 3478 и UDP 49160–49200, настроенные владельцем. Приглашения и ссылка комнаты — разные секреты.

## Возможности 0.4.2, сохранённые в 0.4.3

- Индивидуальные громкость/«Заглушить для себя» сохраняются по аккаунту. Проверьте выход/возврат друга и перезапуск клиента: настройка применяется с первого звука, mute сохраняет выбранную громкость.
- В панели звука можно менять микрофон/вывод во время разговора. Подключите USB-гарнитуру, переключите голос, уведомления и локальную проверку. При потере микрофона передача закрывается; возвращение устройства не включает его само. Проверьте общий gain/deafen и сохранение DSP/PTT.
- Глобальные PTT/mute/deafen включаются в отдельном локальном окне; первоначально режим выключен. Для PTT также выберите «Нажми и говори» в комнате. Проверьте удержание и отпускание в свёрнутом Cacatua, затем в Hunt: Showdown. Ручной mute должен иметь приоритет, удержание mute/deafen не должно многократно переключать состояние. Запишите оконный режим и права запуска игры. Игра/античит и реальные устройства остаются ручной проверкой.
- «Настройки сервера → Управление пользователями…» открывает отдельное окно. Для действий нужна административная сессия; закрытие окна не останавливает сервер/разговор. Проверьте сворачивание, повторное открытие, выход и отзыв сессии. Используйте тестовые аккаунты.
- Приглашение комнаты можно свернуть/раскрыть без смены секрета. Копирование — отдельная кнопка. После смены комнаты или выхода прежние ссылки и административные данные скрываются.
- Звуковые уведомления 0.3.2 сохранены: семь переключателей, громкость 0–100%, явная проверка. PTT, шумовой порог и чужой mute не должны вызывать сигналов.

Разработчик проверяет настоящие Electron/HTTPS/TURN и синтетический PCM, Windows-установку в отдельных профилях и свёрнутые горячие клавиши. Это не заменяет слышимость, акустическое эхо, физическую USB-гарнитуру, Hunt и установку на ваших компьютерах.

При сбое сохраните время/часовой пояс, версии и commit обеих ролей, действие и код ошибки. Скачайте клиентский ZIP у каждого участника и серверный ZIP у владельца; при ошибке запуска — диагностику стартового окна, при установке — экспорт отдельного окна обновления. **Не публикуйте** пароли, ссылки с `#k=`, профили, резервные ZIP, базы, сертификатный private key или ключ издателя.

Постоянный подписанный канал: [client.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/client.json) · [server.json](https://github.com/AbraSare/Cacatua-releases/releases/download/channel-stable/server.json). Подпись, срок, совместимость, размер и hash проверяются приложением; просроченный feed продлевает издатель.
